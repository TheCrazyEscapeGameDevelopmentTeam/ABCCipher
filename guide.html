1. ABC Cipherとは

ABC Cipherは、文章やファイルを暗号化・復号するためのツールです。

暗号化にはAES-256-GCMを使用し、文章の暗号文は a・b・cの3種類の文字だけで表現されます。

暗号化したデータを元に戻すには、暗号化時と同じ鍵が必要です。

2. 暗号鍵の準備

初めて使う場合

  1. ABC Cipherのトップページを開きます。
  2. 暗号鍵を生成するボタンを押します。
  3. 生成された鍵を確認します。
  4. 鍵をファイルに保存します。

鍵ファイルの拡張子は .abckey です。 このファイルを安全な場所に保管してください。

保存済みの鍵を使う場合

  1. 鍵ファイルの読み込み機能を選択します。
  2. 使用する .abckey ファイルを指定します。
  3. 読み込みが完了したことを確認します。

重要： 鍵ファイルには暗号鍵がそのまま保存されています。 他人に渡したり、公開したりしないでください。

3. 文章を暗号化する

  1. 暗号鍵を準備します。
  2. 暗号化したい文章を入力欄に入力します。
  3. 文章の暗号化ボタンを押します。
  4. 表示された暗号文をコピーします。

暗号文はa・b・cだけで構成されます。 コピーした暗号文は、必要な場所に保存してください。

4. 文章を復号する

  1. 暗号化に使用したものと同じ鍵を読み込みます。
  2. 復号したい暗号文を入力欄に貼り付けます。
  3. 文章の復号ボタンを押します。
  4. 復号された文章を確認します。

鍵が異なる場合や暗号文が破損している場合は、 正しく復号できません。

5. ファイルを暗号化する

  1. 暗号鍵を準備します。
  2. ファイルの暗号化機能を選択します。
  3. 暗号化したいファイルを指定します。
  4. 暗号化を開始します。
  5. 保存先を指定する画面が表示された場合は、保存先を選択します。
  6. 処理が完了するまで待ちます。

暗号化されたファイルは .abcdata 形式で保存されます。 元のファイル名やファイル形式などの情報も暗号化されます。

ファイルの大きさによっては、処理に時間がかかる場合があります。 進行状況を確認しながら待ってください。

6. ファイルを復号する

  1. 暗号化に使用したものと同じ鍵を読み込みます。
  2. ファイルの復号機能を選択します。
  3. 復号したい .abcdata ファイルを指定します。
  4. 復号を開始します。
  5. 保存先を指定する画面が表示された場合は、保存先を選択します。
  6. 処理が完了するまで待ちます。

正しく復号できると、元のファイル名とファイル形式で保存されます。

7. 入力内容を消去する

入力内容や暗号文などをまとめて消去したい場合は、 すべて消去する機能を使用します。

この操作では文章の入力欄・暗号文の出力欄・ファイルの選択内容が 消去されます。ただし、読み込み済みの暗号鍵は消去されません。

8. 使用上の注意

  • 暗号鍵を大切に保管してください。 鍵を紛失すると、暗号化したデータを復号できなくなる可能性があります。
  • 暗号鍵を他人に公開しないでください。 鍵ファイルは暗号化されていないため、取り扱いに注意してください。
  • 暗号文や暗号化ファイルを安全に保管してください。 大切なデータは、暗号化前の元データも含めてバックアップを取ることをおすすめします。
  • 通信環境に注意してください。 Web Crypto APIを利用するため、HTTPSまたはlocalhostでの利用を推奨します。
  • 処理中はページを閉じないでください。 ファイルの暗号化・復号中にページを閉じると、処理が中断される場合があります。

9. 困ったときは

「鍵が違うか、暗号文が破損しています」と表示される

使用している鍵が正しいか、暗号文が途中で欠けたり 書き換わったりしていないか確認してください。

ファイルを復号できない

正しい鍵を使用しているか、ファイルが破損していないか確認してください。

暗号化・復号が始まらない

対応しているブラウザを使用しているか、 HTTPSまたはlocalhostでページを開いているか確認してください。

処理に時間がかかる

特に大きなファイルでは、処理に時間がかかることがあります。 進行状況を確認してください。
